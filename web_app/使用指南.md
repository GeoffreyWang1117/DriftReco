## 💻 SmartNet DSL 语法指南

### 🔤 基本语法结构

SmartNet DSL是专门为神经网络定义设计的领域特定语言，语法简洁直观：

```smartnet
# 网络定义
network NetworkName:
    # 全局参数
    input_dim: 128
    output_dim: 10
    learning_rate: 0.001
    
    # 层定义  
    layer layer_name: LayerType(parameters)
    
    # 连接定义
    connection: layer1 -> layer2 -> layer3
```

### 📋 支持的层类型

#### 🟢 Linear层（全连接层）
```smartnet
layer fc1: Linear(128, 64)
# 或带参数名
layer fc2: Linear(input_dim: 128, output_dim: 64)
```

#### 🔵 MultiHeadAttention层（Transformer）
```smartnet
layer attn: MultiHeadAttention(
    embed_dim: 512,
    num_heads: 8,
    dropout: 0.1
)
```

#### 🟠 Conv2d层（卷积层）
```smartnet
layer conv: Conv2d(
    in_channels: 3,
    out_channels: 32, 
    kernel_size: 3,
    stride: 1,
    padding: 1
)
```

#### 🟣 LSTM/GRU层（循环网络）
```smartnet
layer lstm: LSTM(
    input_size: 256,
    hidden_size: 128,
    num_layers: 2,
    dropout: 0.2
)

layer gru: GRU(input_size: 128, hidden_size: 64)
```

### 🔗 连接模式

#### 顺序连接
```smartnet
connection: input -> hidden1 -> hidden2 -> output
```

#### 分支连接
```smartnet
connection: encoder -> [branch1, branch2]
```

#### 合并连接
```smartnet
connection: [branch1, branch2] -> fusion -> output
```

#### 分支定义
```smartnet
branch attention_branch:
    layer attn: MultiHeadAttention(512, num_heads=8)
    layer norm: LayerNorm(512)
    connection: attn -> norm

branch conv_branch:
    layer conv: Conv2d(256, 128, 3)
    layer pool: MaxPool2d(2)
    connection: conv -> pool
    
# 主连接
connection main: backbone -> [attention_branch, conv_branch]
connection merge: [attention_branch, conv_branch] -> fusion
```

### 📝 完整示例

#### 简单分类网络
```smartnet
# 简单三层MLP分类器
network SimpleClassifier:
    input_dim: 784  # MNIST图像大小
    output_dim: 10  # 10个类别
    learning_rate: 0.001
    
    layer flatten: Flatten()
    layer hidden1: Linear(784, 256)
    layer hidden2: Linear(256, 128) 
    layer output: Linear(128, 10)
    
    connection: flatten -> hidden1 -> hidden2 -> output
    activation: relu
    dropout: 0.2
```

#### Transformer编码器
```smartnet
# Transformer编码器网络
network TransformerEncoder:
    input_dim: 512
    output_dim: 10
    learning_rate: 0.0001
    
    layer embedding: Linear(input_dim, 512)
    layer pos_encoding: PositionalEncoding(512)
    
    layer transformer1: MultiHeadAttention(
        embed_dim: 512,
        num_heads: 8,
        dropout: 0.1
    )
    layer norm1: LayerNorm(512)
    layer ffn1: FeedForward(512, 2048, 512)
    layer norm2: LayerNorm(512)
    
    layer classifier: Linear(512, output_dim)
    
    connection: embedding -> pos_encoding -> transformer1 -> norm1 -> ffn1 -> norm2 -> classifier
    activation: gelu
```

#### 多模态网络
```smartnet
# CNN + RNN多模态网络
network MultiModalNet:
    input_dim: [3, 224, 224]  # 图像输入
    sequence_length: 50       # 序列长度
    output_dim: 5
    learning_rate: 0.001
    
    # 图像分支
    branch image_branch:
        layer conv1: Conv2d(3, 64, kernel_size=7, stride=2, padding=3)
        layer bn1: BatchNorm2d(64)
        layer pool1: MaxPool2d(kernel_size=3, stride=2, padding=1)
        
        layer conv2: Conv2d(64, 128, kernel_size=3, padding=1)
        layer bn2: BatchNorm2d(128)
        layer pool2: AdaptiveAvgPool2d(1)
        
        layer flatten: Flatten()
        layer fc_img: Linear(128, 256)
        
        connection: conv1 -> bn1 -> pool1 -> conv2 -> bn2 -> pool2 -> flatten -> fc_img
    
    # 序列分支
    branch sequence_branch:
        layer embedding: Embedding(vocab_size: 10000, embed_dim: 256)
        layer lstm: LSTM(
            input_size: 256,
            hidden_size: 128,
            num_layers: 2,
            dropout: 0.3
        )
        layer fc_seq: Linear(128, 256)
        
        connection: embedding -> lstm -> fc_seq
    
    # 融合层
    layer fusion: Linear(512, 256)  # 256 + 256 = 512
    layer classifier: Linear(256, output_dim)
    
    # 主连接
    connection main: [image_branch, sequence_branch] -> fusion -> classifier
    
    activation: relu
    dropout: 0.1
```

### ⚙️ 参数接口匹配

SmartNet DSL会自动处理不同组件间的接口匹配：

#### 自动维度推导
```smartnet
layer input: Linear(128, 64)
layer hidden: Linear(64, 32)    # 自动匹配输入维度
layer output: Linear(32, 10)    # 自动匹配输入维度

connection: input -> hidden -> output  # 维度自动匹配
```

#### 维度不匹配检测
```smartnet
layer fc1: Linear(128, 64)
layer fc2: Linear(100, 32)  # 错误！输入维度不匹配

# DSL会报错：
# Error: Dimension mismatch - fc1 output (64) != fc2 input (100)
```

#### 分支合并处理
```smartnet
layer branch1: Linear(256, 128)
layer branch2: Linear(256, 128) 
layer fusion: Linear(256, 64)   # 自动计算：128 + 128 = 256

connection: [branch1, branch2] -> fusion  # 自动拼接
```

### 🔄 代码转换功能

#### DSL → PyTorch
点击编辑器中的"PyTorch"标签页，DSL代码会自动转换为PyTorch类：

```python
# 自动生成的PyTorch代码
import torch
import torch.nn as nn
import torch.nn.functional as F

class SimpleClassifier(nn.Module):
    def __init__(self):
        super().__init__()
        
        self.input_dim = 784
        self.output_dim = 10
        
        self.flatten = nn.Flatten()
        self.hidden1 = nn.Linear(784, 256)
        self.hidden2 = nn.Linear(256, 128)
        self.output = nn.Linear(128, 10)
        
    def forward(self, x):
        x = self.flatten(x)
        x = F.relu(self.hidden1(x))
        x = F.relu(self.hidden2(x))
        x = self.output(x)
        return x
```

#### DSL → YAML配置
```yaml
# 自动生成的YAML配置
name: SimpleClassifier

parameters:
  input_dim: 784
  output_dim: 10
  learning_rate: 0.001

layers:
  - name: flatten
    type: Flatten
    parameters: {}
    
  - name: hidden1
    type: Linear
    parameters:
      input_dim: 784
      output_dim: 256
      
connections:
  - from: flatten
    to: hidden1
    type: sequential
```

## 🔧 操作步骤

### 步骤1：配置网络参数

1. 在左侧面板的"网络配置"区域设置：
   - **网络名称**：为您的网络起一个名字
   - **输入维度**：输入数据的特征维度（1-2048）
   - **输出维度**：输出结果的维度（1-100）
   - **学习率**：训练学习率（0.0001-0.1）

### 步骤2：拖拽添加组件

1. 从左侧组件面板选择需要的组件
2. 拖拽到中央画布区域
3. 组件会自动放置并显示默认参数

**可用组件类型：**

| 组件类型 | 说明 | 主要参数 |
|---------|------|----------|
| 🟢 MLP层 | 多层感知机 | 输入/输出维度、隐藏层维度、Dropout |
| 🔵 Transformer层 | 多头注意力 | 输入/输出维度、注意力头数、FFN维度 |
| 🟠 CNN层 | 卷积网络 | 输入/输出通道、卷积核大小、步长 |
| 🟣 RNN层 | 循环网络 | 输入/隐藏维度、层数、类型(LSTM/GRU) |

### 步骤3：调整组件参数

1. 点击画布上的任一组件节点
2. 右侧属性面板会显示该组件的详细参数
3. 根据需要调整参数值：
   - **数值参数**：直接输入数字
   - **选择参数**：从下拉菜单选择
   - **列表参数**：输入JSON格式数组，如`[64, 32]`
4. 点击"应用更改"保存修改

### 步骤4：构建网络

1. 确保已添加至少1个组件
2. 点击顶部"构建网络"按钮
3. 系统会验证网络架构并估算参数量
4. 构建成功后会显示结果对话框

**构建限制（针对双3090优化）：**
- ✅ 最大网络深度：10层
- ✅ 最大参数量：5000万
- ✅ 自动连接验证
- ✅ 内存使用估算

### 步骤5：开始训练

1. 网络构建成功后，"开始训练"按钮会激活
2. 点击按钮打开训练配置对话框
3. 设置训练参数：
   - **训练轮数**：1-100轮（建议10-50轮）
   - **批次大小**：1-256（建议32-128）
   - **学习率**：与网络配置一致或重新设置
   - **GPU选择**：选择要使用的GPU（默认双卡）

4. 点击"开始训练"启动训练任务
5. 训练进度对话框会实时显示：
   - 当前轮次和总轮次
   - 实时损失值
   - 实时准确率
   - 训练日志

## 🔍 故障排除

### 常见问题

**Q1: 组件无法拖拽到画布？**
- ✅ 确保浏览器支持HTML5拖拽
- ✅ 尝试刷新页面
- ✅ 检查JavaScript控制台错误

**Q2: 网络构建失败？**
- ✅ 检查网络深度不超过10层
- ✅ 确认参数量在限制范围内
- ✅ 验证组件参数配置正确

**Q3: 训练无法启动？**
- ✅ 确保网络已成功构建
- ✅ 检查GPU是否可用
- ✅ 验证训练参数在合理范围内

**Q4: 界面显示异常？**
- ✅ 使用现代浏览器（Chrome, Firefox, Safari）
- ✅ 启用JavaScript
- ✅ 清除浏览器缓存

### 错误代码

| 错误信息 | 原因 | 解决方案 |
|---------|------|----------|
| "网络深度过大" | 超过10层限制 | 减少组件数量 |
| "参数量过大" | 超过5000万参数 | 调小网络规模 |
| "GPU不可用" | CUDA环境问题 | 检查GPU驱动 |
